# AI Calendar Planner
Plan your tasks, manage your schedule, and let AI automatically create a realistic study/work plan.
An AI-powered calendar and task management application
built with FastAPI.

## Features

- Calendar management
- Task management
- Priority tracking
- Category filtering
- Search
- Progress tracking
- Overdue detection
- Daily streaks
- AI scheduling assistant

## Tech Stack

Frontend:
HTML
CSS
JavaScript

Backend:
FastAPI
Python

Database:
SQLite / PostgreSQL

AI:
