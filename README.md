# AI Calendar Planner

An AI-powered calendar and task management application
built with FastAPI.

## Features

- Calendar management
- Task management
- Priority tracking
- Category filtering
- Search
- Progress tracking
- Overdue detection
- Daily streaks
- AI scheduling assistant
